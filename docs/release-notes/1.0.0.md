## 1.0.0

首个版本：基于上游 FluentFlyout **2.15.0** 的修复分支，并移除了 Premium / Microsoft Store / 遥测相关代码。

- 修复了上游的若干缺陷：设置保存与恢复、媒体会话与播放/暂停图标、主题跟随与窗口外观、音量浮窗定位、任务栏小组件与可视化、本地化、ARM64 构建等。逐项说明见 [CodeRepairRecord.md](https://github.com/Zerin-emm/FluentFlyout/blob/main/docs/CodeRepairRecord.md)。
- 代码分析，以及「哪些激进手段是平台所迫、不算缺陷」见 [CodeAnalysis.md](https://github.com/Zerin-emm/FluentFlyout/blob/main/docs/CodeAnalysis.md)。
- 支持 Windows 11（22000+）；安装包分 x64 与 ARM64 两版。
